# Rucha Keni Portfolio

Dark editorial portfolio for **Rucha Dilip Keni**, supply chain / data analyst. Content is taken from the supply-chain resume (experience, metrics, projects, skills, and education).

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## What’s included

- Experience from Holiday Channel, Barnes & Noble Education, Capgemini, and Siemens
- Impact metrics pulled from the resume
- Featured GitHub projects
- Downloadable resume at `/RuchaKeni_Resume.pdf`
